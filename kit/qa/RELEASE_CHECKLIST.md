# Release checklist

All items begin unverified. Link evidence next to each checked item.

- [ ] All 25 acceptance rows completed against named release candidate.
- [ ] 24 base rooms and 12 remixes validate and complete; required alternate witnesses pass.
- [ ] Fun/comprehension gate reviewed with actual participants.
- [ ] Physical device matrix, interruption/soak, offline, input and performance budgets pass.
- [ ] Save backup/migration/corruption/process-kill behavior verified.
- [ ] Final art/audio, sources/licenses, credits and localization audit complete.
- [ ] Muted play, enlarged text, reduced motion, safe areas and menu labels verified.
- [ ] Binary SDK/network audit agrees with privacy disclosures; no undisclosed analytics.
- [ ] Title availability and final brand selected by owner.
- [ ] Final bundle/package IDs, app versions, price, countries and support contact supplied.
- [ ] Current Google/Apple requirements rechecked from official sources.
- [ ] Android signed AAB manifest and target API verified; keystore backed up securely.
- [ ] iOS signed archive, SDK, deployment target, capabilities and team verified on Mac.
- [ ] Secrets absent from repository, logs and distributable kit.
- [ ] Screenshots come from the shipping build; store descriptions match real features.
- [ ] Privacy page, support contact and content ratings are complete and accurate.
- [ ] Source tag, clean-checkout build instructions, content revision and save fixtures retained.
- [ ] Owner reviewed actual release candidate and explicitly authorized submission.

Publishing is not authorized merely by completing this checklist. Do all preparatory work before the final publication decision.
